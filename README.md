# 火锅店预约系统

## 项目简介
火锅店预约系统由管理端和客户端构成。
管理端前端是用Vue+Element Plus开发，管理端后端是用Spring Boot+MyBatis Plus开发。
客户端是用Vue+Vant开发，适配移动端。
数据库用的是MySQL。
总体来说涉及的技术比较广，难度适中，都是市面上主流的技术，非常适合作为设计项目或开发学习。
## 功能介绍

### 管理端功能

#### 权限管理
- 管理台：系统概览、数据统计
- 用户管理：用户信息管理、用户权限分配
- 角色管理：角色创建、权限分配
- 权限管理：菜单权限、操作权限管理
- 日志管理：登录日志、操作日志

#### 业务管理
- 公告管理：公告发布、编辑、删除
- 客户管理：客户信息管理、客户标签
- 菜单管理：菜品种类管理、菜品管理（添加、编辑、删除、图片上传）
- 订单管理：订单查询、状态更新、订单详情、订单统计
- 支付管理：支付记录查询、退款管理
- 预约管理：预约日历、预约管理、预约审核、预约统计
- 评论管理：评论查看、回复、删除
- 桌位管理：桌位布局、桌位状态管理

#### 报表统计
- 销售报表：销售额、销售量、客单价统计
- 库存报表：库存情况、每日消耗、采购建议
- 客户报表：客户消费行为分析、客户价值评估

### 客户端功能
- 首页：轮播图、公告、推荐菜品
- 菜单浏览：分类浏览、菜品搜索
- 点餐：菜品详情、数量选择、口味选择
- 购物车管理：商品数量调整、删除商品
- 下单：订单确认、支付方式选择
- 订单管理：历史订单、订单状态查询、订单详情
- 预约管理：桌位预约、预约状态查询
- 评论管理：菜品评论、评论查看
- 个人中心：个人信息管理、地址管理
